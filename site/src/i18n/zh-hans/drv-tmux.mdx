<Mdx.h3 id="delivery-you-can-trust">可靠的投递</Mdx.h3>

向窗格输入之前，tmt 会检查该窗格在同一个 tmux 服务器上是否仍属于你指定的名称。如果发送可能只完成了一部分（例如已粘贴文本，但未确认按下 Enter），tmt 会报告**不确定**，绝不会自行重发。先用 `tmt check <name>` 查看，再作决定。

<Mdx.h3 id="the-pane-badge">窗格徽标</Mdx.h3>

每个已命名的窗格都会获得一个小标签，你可以将它放在自己的窗格边框中。它默认开启：

<BadgeBorders />

<Cmd>{`$ tmt config set ui.paneBadge off --global   # 关闭`}</Cmd>

然后在自己的 `pane-border-format` 中，将以下片段添加到你想显示它的位置：

<Code>{`#{?@tmux-team.badge, [#{@tmux-team.badge}],}`}</Code>

该选项保留了 tmt 的旧名称 tmux-team，以便现有配置继续可用。tmt 只通过一个窗格选项提供标签，不会修改窗格标题、边框格式、布局或主题；徽标的位置由你决定。圆点显示的是记录下来的会话状态，不表示 agent 是否忙碌。

<Mdx.h3 id="when-tmux-says-no">tmux 拒绝访问时</Mdx.h3>

有些 agent 沙箱会阻止访问 tmux socket。此时 tmt 会明确说明：无法访问 socket，可能是沙箱阻止了访问，且没有向任何窗格输入内容。它不会将窗格报告为不存在。需要在 agent 一侧解决：通过 agent 自身的权限提升机制重新运行同一条命令，或者允许访问 socket。
