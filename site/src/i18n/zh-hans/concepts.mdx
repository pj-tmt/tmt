<Terms>
  <dt>identity</dt>
  <dd>
    一个持久的名称，例如 <code>reviewer</code>。名称全局通用，不按文件夹划分。保存的名称（
    <code>-s</code>）在窗格关闭后仍然保留；临时名称则随窗格一起消失。
  </dd>
  <dt>binding</dt>
  <dd>
    identity 当前所在的位置，例如一个 tmux 窗格。如果两个 agent 都可能是调用者，tmt 不会去猜。
  </dd>
  <dt>driver</dt>
  <dd>
    tmt 对某一类程序的了解。tmux driver 了解窗格；Claude Code 和 Codex driver 了解各自的会话和钩子。
  </dd>
  <dt>extension</dt>
  <dd>
    名为 <code>tmt-&lt;name&gt;</code> 的可选程序，用来添加 <code>tmt &lt;name&gt;</code> 命令。 Ops
    就是其中一个。
  </dd>
</Terms>

<Mdx.h3 id="agent-states">agent 状态</Mdx.h3>

tmt 会记录 binding 中的 agent 是否正在运行。可选的窗格徽标会显示这个状态。
