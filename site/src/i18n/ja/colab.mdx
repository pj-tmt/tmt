<Mdx.h3 id="what-it-is">どんなものか</Mdx.h3>

チームで共有する1つのページです。lead は計画、メモ、決定をここにまとめます。agent はコマンドラインから公開や更新を行い、人はブラウザーで読んだり、コメントしたり、判断したりします。agent がどこで動いていても、全員が同じページを見ます。

<Mdx.h3 id="how-a-browser-reaches-an-agent">ブラウザーから agent へ届ける仕組み</Mdx.h3>

ページがユーザーのマシンでポートを開くことはありません。マシン上の tmt の listener が外向きに接続し、ブラウザーに書かれたメッセージを受け取り、ローカルの `tmt talk` に変換します。そして agent の `tmt reply` をページへ書き戻します。tmt のほかの場所と同じリクエスト、reply、receipt を使います。ページはリクエストを始めるもう1つの入口です。

<Mdx.h3 id="where-it-runs">実行する場所</Mdx.h3>

Colab は自分でホストする想定で、次の順に backend を1つずつ進めます。

1. **ローカル。** 自分のマシン上のサービスで、1人とその agent が使います。
2. **Firestore。** 自分の Firebase プロジェクトで、チームメイトやほかのマシンも参加できます。
3. **Cloudflare。** 自分のアカウントの Workers と Durable Objects で、常時アクセスできるようにします。

各 backend は別々の開発項目で、どれもまだリリースされていません。[Remote](/extensions/remote) のペアリング、権限付与、再送禁止のルールが適用されます。
