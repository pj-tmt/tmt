<Mdx.h3 id="principles">原則</Mdx.h3>

- **顏色表達意義。** 畫面大部分保持中性，只有需要你處理、正在工作或卡住的內容才突出顯示。
- **不能只靠顏色。** 每個狀態也要用符號或文字表示，例如 `◆2` 或 `blocked`，讓 `NO_COLOR`、管線、螢幕閱讀器與色覺差異都不影響理解。
- **終端機決定色調。** 命令列的 token 指向終端機的 16 種顏色之一，由使用者的主題決定實際色調。網站與全螢幕 board 的 truecolor 主題使用下方的精確數值。
- **共用一套含義。** token 在各處代表相同意義。無論是 board 的分頁、`tmt ls` 的一列或網站標籤，`waiting` 都表示需要你處理。

命令列自己的 token 名稱（`accent`、`ok`、`warn`、`error`、`dim` 與 driver 顏色）也對應這些顏色：`ok` 對應 `working`，`warn` 對應 `waiting`，`error` 對應 `blocked`，Claude 與 Codex 的 driver 顏色分別對應 `review` 與 `link`。完整列表見 [design/cli-style.md](https://github.com/pj-tmt/tmt/blob/main/design/cli-style.md)。終端機主題也從同一份檔案讀取數值，兩者不一致時測試會失敗。
