Any program named `tmt-<name>` on your PATH becomes `tmt <name>`, the way components add commands to gcloud. Built-in commands always win, so an extension can't replace `talk` or `run`. Extensions reach tmt through its commands, JSON output and hooks, the same doors any other program uses.

<Cmd>{`
$ tmt sq board         # runs tmt-squad board
$ tmt help             # lists extensions it found
$ tmt sq <Tab>         # completion comes from the extension
`}</Cmd>

### Install, update and remove

The extensions below are installed the same way. Each one has its own version and updates on its own schedule, and removing one keeps its data.

<Cmd>{`
$ tmt extension install squad     # asks before changing anything
$ tmt extension list              # what's installed, versions, updates
$ tmt extension upgrade squad
$ tmt extension uninstall squad   # your data stays
`}</Cmd>

If an extension comes with skills for your agents, install asks whether to add them too. To write your own extension, see [Build an extension](/develop/extensions). Any `tmt-<name>` on your PATH works without `tmt extension`.
