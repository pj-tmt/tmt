### Connect it

<Cmd>{`
$ tmt setup codex           # shows the exact config change, then asks
$ tmt run builder codex     # start Codex as "builder"
$ tmt resume builder        # reopen builder's own thread
`}</Cmd>

Setup adds Codex's lifecycle hooks for tmt. Codex asks you to trust new hooks the first time; that's expected. `tmt setup codex --remove` takes them out again.

### Codex's sandbox

In Codex's workspace-write sandbox, Codex can't write tmt's data directory by default. tmt reports this plainly as storage that isn't writable, not as a crash. It points to the one setting that allows it: adding tmt's data directory to Codex's `writable_roots`. `tmt setup codex` offers to add it for you and only does so with your OK.
