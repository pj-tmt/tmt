Claude: bigger plan, not four times bigger

  • Max 5x → Max 20x roughly 1.7× per 1%. $16–18 before, $26–35 after. Max 20x is sold as four times Max 5x.
  • A full Max 20x week held about $2,500–2,900 of our work.
  • Sonnet weeks bought less per percent. Windows that were about half Sonnet came in at $26–29; Opus-heavy windows at $30–35. Sonnet appears to use more of the limit than its API price suggests.
  • Cache reads are most of the value. Long-running agents keep reading the same context.

So which $200?

More dollars of API value is not more work. Different models need very different amounts of tokens for the same task.

  • A Pro 200 window fits about twice as many Sol tasks as a Max 20x window fits Opus tasks, even though the Claude window holds three times the dollars.
  • Opus scores 2 points higher and spends about three times the output tokens to get there. At max effort the gap is wider: Opus 58 at $10.04 a task, Sol 55 at $1.27 (v5 launch).
  • If the Codex doubling holds, the gap widens. We haven't measured a full window since.
  • For our own work, a merged PR led by Sol 6.1 cost a median $5.5 of API value; one led by Terra 6.1, $4.7.

We use both: Claude for the leads that review and decide, Codex for most of the implementation. The benchmark is one workload. Your mix decides your answer.

How we measured

  • Sources: Claude Code transcripts and Codex session logs on the one machine the team runs on, 27 September to 30 October. Messages deduplicated by ID; automatic code review excluded.
  • Prices: public API list prices (Claude, OpenAI), fast mode at 2×. It is a ruler, not a bill.
  • Percent: read from each tool's status line, whole numbers only, so short windows carry about 5–8% error.
  • Gaps: Codex logs before 11 October were pruned; usage on web apps or other machines is not counted; squad labels are inferred from identities and worktrees.

Why we track it

TMT's digest watches how fast each squad burns its window and paces the team so it doesn't hit a wall on day three. That only works if we know what 1% is really worth. When a plan changes, we want to see it in our own numbers first.
