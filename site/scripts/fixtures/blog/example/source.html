An article can explain an idea and let the reader explore it. This example uses a deliberately simple model: every member can talk directly to every other member.

Try the model

Move the slider to change the number of members. The result counts pairs, not real messages or measured TMT performance.

How many connections?

6 possible pairs

Each pair is counted once: n × (n − 1) ÷ 2.
