Pair this browser

  1. In the terminal on the machine running Remote, run tmt remote pair.
  2. Open the link it prints in this browser. If another browser opens automatically, paste the full link into this browser’s address bar.
  3. Enter a device name and choose Pair. Compare the four words on the page with the terminal.
  4. If the words match, confirm in the terminal. Return here to connect with your saved pairing.

Keep the pairing link private. A link that no longer works needs a new tmt remote pair offer.

For a saved pairing that loses access, inspect it locally with tmt remote devices. Pairing again requires your explicit terminal confirmation.
