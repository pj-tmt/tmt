Checking the connection…

Reading this browser's pairing.

  1. On the machine running Remote, run tmt remote pair.
  2. Open the link it prints in this browser.
  3. Name this device, then check that the four words match the terminal.
  4. Confirm in the terminal. This page updates when you come back.
  1. To use this machine too, run tmt remote pair on it.
  1. Check this device with tmt remote devices.
  2. If it's missing, pair again with tmt remote pair.
  1. Check Remote is running: tmt remote status.
  1. Pair again with tmt remote pair.

Run these commands on the machine that runs Remote.

tmt remote pair
tmt remote devices
tmt remote status
