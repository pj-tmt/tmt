# Ops UI configuration migration

The interactive board uses Agents and Digest as a direct replacement for the former squad-tab and HOME layouts. There is no legacy UI or legacy-default preset. Compatible explicit bindings override the new defaults; unsupported actions/scopes/settings are reported and require deliberate migration. User files are preserved until a confirmed, format-preserving write.

## Controls and key ownership

| Previous control                                                                                                             | Current workspace behavior                                                                                                                                                                                                                                                                                                                                                               |
| ---------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Enter/double-click = host jump in tmux, menu in plain terminal; aggregate Enter = squad tab                                  | Enter selects/activates the workspace target; `j` explicitly goes to host when available, Menu is an action. Single click selects. Old explicit `jump` remains host-specific.                                                                                                                                                                                                            |
| Up/Down and j/k navigate; PageUp/Down/Home/End scroll/select                                                                 | Arrows and paging retain navigation. Agents `j` becomes Host; reader/picker j/k remain navigation. No global j/k interception ahead of scoped bindings.                                                                                                                                                                                                                         |
| Left/Right change old squad tabs; Shift+Left/Right reorder them                                                              | Three shell tabs selected by guarded 1/2/3; remove old per-squad-tab reorder. Located migration notices explicitly name old Left/Right and Shift+Left/Right behavior; no invisible fallback retains it. Squad sorting/pinning is the workspace successor.                                                                                                                                |
| `s` conditional switcher fallback                                                                                            | Sort/reverse-sort is available through authored bindings and changes the current view layer. The old switcher/default is retired; compatible explicit bindings retain precedence.                                                                                                                                                                                               |
| `t` Talk; `o` Open; `c` conditional cron list                                                                                | Keep `t` Talk and `o` Link; `c` Timers. In list scope add `x` Remove membership, `m` Add/reassign, `p` Pin, `n` Create squad. Member rows retain `D` Digest. Member Rename is deferred to Core #2986; WP2 has no member `r` binding or hint. `w` is reserved for WP5 snapshots and cannot be rebound to another list action in WP2. Reader and cron p/x/o/d retain their local meanings. |
| `a` annotate lead; `A` ask-lead on member boards or home-write on aggregate; `e` home-message; `v` view-reply; `@` home-pick | Remove implicit aggregate/lead-target defaults. Select the named lead/member and use WP1 Talk/conversation; annotation, reply and recipient choice remain explicit actions. No automatic migration to a different recipient.                                                                                                                                                             |
| `i` Digest; `n` Notes; `y` Copy; `d` conditional detail/replies fold; Backspace = back                                       | Digest tab 3 and member `D` Digest; `n` now Create squad. Copy and Back remain compatible explicit actions. Notes-pane bindings are reported for explicit migration. Remove the old default fold action; new layout preference replaces manual factory-pane folding.                                                                                                                     |
| Tab = next pane; `/` search; `?` help; `,` settings; Ctrl-R refresh; q/Esc/Ctrl-C quit/back                                  | Keep scoped focus traversal/search/help/settings/refresh and close/quit semantics; inputs/modal owners run first. Preserve Ctrl-R override behavior and explicit refresh bindings. No shell digits fire in editors, search, completion, picker or popup.                                                                                                                                 |

Config owns one effective table in each list/Reader scope: defaults, compatible
explicit global bindings, host bindings, then section bindings. Help and footer
show the action dispatch will run. Explicit `q` bindings are accepted; Ctrl-C
remains non-bindable. No unavailable action guesses a recipient. Before data
arrives, the same Config-owned defaults operate the three shell tabs.

Overlay-local contracts remain scoped: reader Esc/q/v close, s source selection, y copy, a annotate; cron n/e/E/p/x/o/d/v and Enter observed squad; settings text/Enter/Esc/Ctrl-U and reset; help Esc/?/q; form Tab/BackTab/Enter/Ctrl-N/Shift-Enter/Ctrl-U; Picker query/list handling; WP1 completion gets arrows/Enter/Tab/Esc first. Validate scope collisions against these real consumers, not an empty replacement table. The bottom footer is the single key legend; content buttons use action names, except the accepted inline link hint.
