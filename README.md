# tmt

Your coding agents, working together: send work to an agent's terminal pane by
name and get complete replies back. A standalone native CLI for macOS and Linux.

tmt is an early alpha and changes quickly, so this README stays short on purpose.

```sh
curl -fsSL https://install.tmt.ninja | sh
```

Then run `tmt --help` or `tmt learn`.

Installing and upgrading need no GitHub token. The first upgrade from an older release may still call the GitHub API.
